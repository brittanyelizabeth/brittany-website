# Brittany Massage & Wellness website

A responsive, single-page website template customized with:
- Brand name: Brittany
- Contact email: BrittanyElizabeth20072005@gmail.com
- Services section, about section, appointment enquiry form, mobile navigation
- Appointment form opens the visitor's email app with an enquiry pre-filled

## Preview locally
Open `index.html` in a browser. Internet access is needed to load the Google Fonts and the remote Unsplash photos.

## Publish online with Vercel
1. Sign in to Vercel and create a new project.
2. Upload these files to a GitHub repository (or import an existing repository).
3. Import the repository into Vercel and deploy as a static site.
4. After deployment, Vercel will provide a public URL.

## Important customization notes
This is an original starter design inspired by common massage/wellness website layouts; it is not a copy of the source website's proprietary code. Replace the stock photos, confirm the real services/prices/location, and add a real booking or form backend if you want submissions stored automatically. The current form opens the visitor's email app and does not send automatically.
